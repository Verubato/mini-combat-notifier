# MiniCombatNotifier

Simple addon that shows text on your screen when entering and leaving combat.

By default the Blizzard scrolling combat text does this, however many of us disable it as it's far too spamy but then we no longer get notified of entering/leaving combat; this addon fixes that.

There's currently no configuration UI for this, but you can tweak the settings by "/tinspect MiniCombatNotifierDB" and click inside the rows to tweak the values.

This is a brand new addon and features will be added over time.

Feedback and feature requests are more than welcome!
